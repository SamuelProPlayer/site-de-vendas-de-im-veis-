# Documento de Requisitos do Produto (PRD)

## 1. Identificação
* **Autor:** Samuel Binsfeld de Lara
* **Nome do Projeto:** SA incorporadora - Portal Imobiliário de Luxo
* **Tema:** Plataforma para venda, exibição e agendamento de visitas em propriedades de alto padrão num condomínio fechado.

## 2. Descrição e Propósito
O **SA incorporadora** é uma aplicação web voltada para a comercialização de cpropiedades de alto padrão em um condomínio fechado. O sistema resolve o problema da falta de informações detalhadas e visuais sobre os imóveis, permitindo ao comprador explorar as propriedades, filtrar características e agendar visitas com um corretor.

## 3. Atores do Sistema
* **Visitante / Comprador:** Usuário interessado em visualizar o catálogo de imóveis e agendar visitas.
* **Corretor / Administrador:** Responsável por visualizar as solicitações de visita e atualizar o catálogo.

## 4. Histórias de Usuário (User Stories)

* **US01:** Como **Visitante**, quero **filtrar imóveis por preço, quantidade de quartos e área (m²)**, para **encontrar a casa ideal rapidamente**.
* **US02:** Como **Visitante**, quero **visualizar uma galeria de fotos e detalhes técnicos de cada casa**, para **avaliar as opções disponíveis**.
* **US03:** Como **Visitante**, quero **preencher um formulário de agendamento de visita**, para **solicitar atendimento com um corretor**.
* **US04:** Como **Visitante**, quero **visualizar a cotação das moedas (dólar/euro) ou previsão do tempo local na página via API pública**, para **planejar o agendamento de visita**.
