# 📖 Descrição do Projeto

A SA Central de Vendas é uma aplicação web responsiva desenvolvida para auxiliar na apresentação e comercialização de residências exclusivas e terrenos de alto padrão em um condomínio fechado.
A aplicação permitirá que o usuário navegue pelo catálogo de imóveis, utilize filtros avançados (como faixa de preço, metragem e quantidade de quartos) e acesse uma página com especificações técnicas completas de cada propriedade. Além disso, o sistema contará com um formulário de agendamento de visitas com corretor.
O objetivo é centralizar as informações dos imóveis e facilitar o contato entre compradores e a equipe de vendas em uma interface sofisticada e intuitiva.
A SA Central de Vendas possui caráter exclusivamente informativo e de intermediação. A aplicação não realizará transações financeiras reais, pagamentos ou transferência de títulos de propriedade.
